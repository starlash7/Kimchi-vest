# 🚀 Kimchi-vest (김치-베스트)

**AI 기반 Solana Pump.fun 예측 시장 플랫폼**  
*Pump.fun의 졸업(Graduation)을 실시간 AI로 예측하고 배팅하세요.*

---

## 📜 프로젝트 개념 (Concept)
**Kimchi-vest**는 솔라나 에코시스템의 Meme-coin 런치패드인 **Pump.fun**에서 발행되는 수많은 토큰들의 성공 여부를 예측하는 인텔리전트 예측 시장입니다. 

단순한 도박이 아닌, **AI Market Maker Agent**가 실시간으로 온체인 데이터를 분석하여 토큰이 '졸업(Raydium 상장)'할 확률을 계산하고, 이에 따른 동적 배당률(Dynamic Odds)을 제공합니다. 유저들은 AI의 분석 리포트를 참고하여 승률 높은 예측에 참여할 수 있습니다.

## 🤖 AI Agent: Market Maker
이 프로젝트의 핵심은 백엔드에서 작동하는 **AI Market Maker Agent**입니다.

- **실시간 스캐닝**: Pump.fun에 새롭게 생성되는 모든 토큰의 스마트 컨트랙트 및 초기 유동성을 감시합니다.
- **본딩 커브 분석**: 토큰의 매수/매도 패턴을 분석하여 본딩 커브(Bonding Curve) 졸업 가능성을 초 단위로 업데이트합니다.
- **동적 배당 로직**: 시장의 참여도와 AI 예측 모델을 결합하여 공정한 배당률을 실시간으로 산출합니다.

## 🛠️ 기술 스택 (Tech Stack)
- **Frontend**: Next.js 14 (App Router), TypeScript, Vanilla CSS (Premium Claymorphism UI)
- **Authentication**: **Privy SDK** (Social Login & Embedded Wallets)
- **Blockchain**: Solana Mainnet-Beta (via web3.js)
- **Design Style**: Retro-Tech Futurism (inspired by things.inc), High-Fidelity Claymorphism
- **AI Integration**: AI Agent Node (Market Maker logic)

## ✨ 주요 기능 (Key Features)
1. **Live Oracle Feed**: 현재 가장 유망한 토큰들의 실시간 상태와 AI 점수를 한눈에 확인.
2. **One-Tap Betting**: Privy를 통한 간편한 지갑 연결과 솔라나 기반의 빠른 예측 참여.
3. **AI Terminal Logs**: AI 에이전트가 현재 어떤 데이터를 분석하고 있는지 실시간으로 로그 중계.
4. **Premium Dashboard**: 스크롤 없이 모든 정보를 파악할 수 있는 고품격 벤토 그리드(Bento-Grid) UI.
